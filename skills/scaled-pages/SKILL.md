# 대량 생성 페이지(지역·월·카테고리 조합)

근거(확인 2026-11-04): Google [스팸 정책 — 확장된 콘텐츠 악용·도어웨이](https://developers.google.com/search/docs/essentials/spam-policies?hl=ko), [유용한 콘텐츠](https://developers.google.com/search/docs/fundamentals/creating-helpful-content?hl=ko), 네이버 [웹 콘텐츠 스팸사례 — 저품질 콘텐츠 대량 생성](https://searchadvisor.naver.com/guide/content-abusing), [콘텐츠 작성시 권장 사항](https://searchadvisor.naver.com/guide/content-basic). 구성 아이디어는 [coreyhaines31/marketingskills `programmatic-seo`](https://github.com/coreyhaines31/marketingskills/tree/main/skills/programmatic-seo)(MIT)를 참고했습니다.

## 두 검색엔진의 기준

- Google: 사용자를 돕기보다 순위 조작을 주목적으로 많은 페이지를 만드는 것은 **생성 방법과 관계없이** 확장된 콘텐츠 악용.
- 네이버: 동일·유사 템플릿으로 문장 일부만 바꾼 페이지를 대량 발행하면 저품질 콘텐츠 대량 생성. AI·자동화 사용 여부만으로 판단하지 않음.
- 즉, **템플릿 자체가 문제가 아니라 페이지마다 고유한 실제 정보가 있는지**가 기준입니다.

## 색인할 조합 정하기

| 조건 | 처리 |
| --- | --- |
| 실제 항목이 1개 이상 있고, 그 조합으로 검색할 이유가 있음(예: `서울 + 2026년 12월`에 실제 행사 3건) | 색인. 고유 title·h1·설명, 항목 목록, 내부 링크 |
| 항목 0건 | 페이지를 만들지 않거나, 만들면 `noindex` + 사용자용 안내(빈 결과·다른 달 링크). 200으로 "결과 없음"만 보여 주는 페이지를 사이트맵에 넣지 않음 |
| 다른 조합과 항목이 완전히 같음(예: `경기 전체`와 `경기 + 이번 달`이 같은 목록) | 하나를 대표로 canonical, 다른 하나는 사이트맵 제외 |
| 정렬·필터·페이지 크기 파라미터(`?sort=`, `?view=`) | 대표 URL canonical, 사이트맵 제외 |
| 다중 필터 조합(지역×월×카테고리×무료…) | 무한 조합을 색인 대상으로 늘리지 않음. 색인은 미리 정한 1~2단계 조합만 |

## 각 페이지에 있어야 할 고유 정보

- 그 조합에만 해당하는 실제 항목 목록과 개수, 기간
- 항목별 핵심 사실(날짜·장소·상태)과 상세 페이지 `<a href>` 링크
- 마지막 확인 시각·출처(사실 정보 사이트라면)
- 주변 조합으로의 링크(이전·다음 달, 인접 지역)
- 피할 것: 지역명만 바꾼 같은 소개 문단, 키워드 반복 문장("서울 베이비페어 서울 베이비페어 일정"), 없는 정보 채우기

## 제목·설명 템플릿

- title: `<지역> <키워드> <YYYY년 M월> 일정 <N>건 | <사이트명>` — 건수·기간처럼 페이지마다 실제로 달라지는 값을 넣습니다.
- description: 실제 첫 항목 몇 개의 이름·날짜를 요약. 모든 페이지에 같은 문장을 쓰지 않습니다.
- 매달 같은 URL을 재사용하는 페이지(`/seoul/this-month`)는 제목의 연·월을 갱신합니다(Google 제목 링크 문서).

## 점검 순서

1. 생성될 조합 수를 먼저 계산하고, 그중 항목 1건 이상인 조합 수를 셉니다.
2. 빈 조합·중복 조합의 처리(미생성/noindex/canonical)를 정합니다.
3. 사이트맵에는 색인할 조합과 상세 페이지만 넣습니다.
4. 표본 페이지 몇 개를 열어 문단이 지역명만 다른지 확인합니다.
5. 공개 후 Search Console·서치어드바이저에서 색인되지 않은 상태로 남는 페이지가 많은 조합 유형을 찾아 줄이거나 합칩니다.
